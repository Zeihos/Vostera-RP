# Политика безопасности

VOSTERA ROLEPLAY находится в разработке. Публичного релиза игрового сервера пока нет. Для актуального состояния см. [план разработки](./docs/roadmap.md).

## Как сообщить об уязвимости

**Не публикуйте в открытом Issue** рабочие эксплойты, секреты, конфигурации серверов или данные пользователей. Если в GitHub доступна функция **Private vulnerability reporting**, используйте вкладку `Security` → `Report a vulnerability`. Если она не включена, свяжитесь с командой проекта через личные сообщения сообщества [VK](https://vk.ru/vostera_rp) и попросите приватный канал передачи технических деталей.

Укажите затронутый компонент (сайт/форум/Wiki), версию или SHA коммита, условия воспроизведения и последствия. Приложения очистите от персональных и секретных данных. Не проводите тесты на чужом действующем сервере без разрешения владельца.

## Известные ограничения

- Старые одноразовые установочные ключи форума и Wiki ранее находились в **публичной истории Git**. Они больше не должны использоваться. Перед новой установкой генерируйте секреты через `php tools/prepare-install.php`.
- Установленные серверы должны хранить `private/` вне веб-корня; GitHub CI не проверяет конфигурацию конкретного хостинга.
- Файловые хранилища требуют резервного копирования и оценки эксплуатационных рисков.
- Отсутствие критических находок в статических проверках не равно готовности к публичной эксплуатации.

Не отправляйте исправления с паролями или реальными данными игроков даже в закрытый PR.
