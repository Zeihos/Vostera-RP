# Развёртывание VOSTERA ROLEPLAY

## Требования

- PHP **8.1+** с расширениями `json`, `session` (для Wiki также `fileinfo`; дополнительные требования указаны в `INSTALL.txt`).
- HTTPS на публичном домене. Рекомендуются отдельные поддомены для сайта, форума и Wiki.
- Право записи PHP в рабочие хранилища форума и Wiki; **не используйте права `777`**.
- Для CI/локальных тестов — Python 3.10+; для игрового мода позже понадобятся Pawn-компилятор и MariaDB.

## Сайт

1. Разместите содержимое `Сайт/` в корне отдельного сайта.
2. Укажите реальные адреса в `Сайт/config/site.php`: `domain`, `forum_url`, `launcher_url`, `servers` и другие доступные параметры.
3. Убедитесь, что `config/`, `includes/` и `data/` нельзя читать через HTTP (на Nginx настройте `deny`; правила Apache сами по себе Nginx не защищают).
4. Мониторинг использует UDP, а некоторые хостинги блокируют исходящие запросы. Проверьте разрешения сети. Пока адреса серверов не заданы, данные онлайна не появятся.
5. Не включайте реальные платежи до отдельной проверки безопасности и подключения платёжного провайдера.

Локально: `php -S 127.0.0.1:8786 -t Сайт` из корня репозитория.

## Форум

1. Поместите **обе** директории `Форум/public` и `Форум/private` на сервер, но укажите document root **только** на `Форум/public`.
2. В каталоге `Форум` запустите `php tools/prepare-install.php`. Ключ покажется в терминале один раз.
3. Откройте `https://адрес-форума/install`, введите ключ и создайте администратора.
4. Укажите свои адреса в `private/config.php`. Сделайте резервную копию `private/store.json`.
5. Полные требования и восстановление до установки: [`Форум/INSTALL.txt`](../Форум/INSTALL.txt).

Локально из каталога `Форум`: `php -S 127.0.0.1:8787 -t public public/router.php`.

## Wiki

1. Аналогично назначьте document root **только** на `Вики/public`.
2. Перед **первой** установкой из `Вики` выполните `php tools/prepare-install.php`. Будут созданы рабочая база `private/data.json` из примера и уникальные секреты.
3. Откройте `/install`, создайте владельца. Затем настройте фактические адреса сайта и форума.
4. Если Wiki **уже установлена**: перед обновлением скопируйте `private/data.json` и `public/uploads/`. **Не перезаписывайте** их. Для ранее установленной версии предусмотрена команда `php tools/prepare-install.php --migrate` — прочитайте подробности в [`Вики/INSTALL.txt`](../Вики/INSTALL.txt).

Локально из каталога `Вики`: `php -S 127.0.0.1:8788 -t public public/router.php`.

## Обязательные меры перед публикацией

- Проверить HTTPS, права доступа, отсутствие внешнего доступа к `private/`, конфигурации и резервным копиям.
- Удалить или заменить старые установочные ключи из ранней истории репозитория. **Они были публично доступны**, их нельзя использовать повторно.
- Настроить резервные копии: отдельно `Форум/private/store.json`, `Вики/private/data.json` и `Вики/public/uploads/`.
- Не отправлять в GitHub рабочие файлы данных и `.env`; использовать `.gitignore` и проверку `python3 tools/check_repository.py`.
- Протестировать регистрацию, вход, роли, восстановление данных из копии и ограничения доступа **на собственном хостинге**. HTTP smoke-тесты CI не заменяют эксплуатационный аудит.
