VOSTERA ROLEPLAY — WIKI v1.0
==========================

ГОТОВО: 7 категорий и 24 стартовые статьи; поиск; обратная связь; Markdown-редактор;
панель управления; роли владелец / администратор / редактор; загрузка изображений.

ТРЕБОВАНИЯ
- PHP 8.1 или новее, расширения: json, session, fileinfo (для изображений).
- Отдельная база данных, Chatwoot и Composer не нужны.
- PHP должен иметь право изменять private/data.json и создавать файлы в public/uploads.
- Для публичного сайта обязательно используйте HTTPS и резервные копии.

УСТАНОВКА НА ХОСТИНГ
1. Загрузите обе папки — public и private — в одну директорию.
2. Настройте корень сайта/subdomain на папку public. НЕ раскрывайте private в вебе.
   Рекомендуемый адрес: wiki.ваш-домен (отдельно от игрового сайта и форума).
3. Дайте PHP права записи в private/data.json и public/uploads (не выставляйте 777).
4. Откройте https://wiki.ваш-домен/install
5. Введите ключ установки (один раз):

T-_7KEciqNQwRe_Dljfpec0cMCJF6eHK

6. Создайте владельца с надёжным паролем не короче 12 символов.
7. Откройте /admin/settings и укажите РЕАЛЬНЫЕ адреса игрового сайта, форума и клиента.
8. В /admin/articles обновите статьи о запуске и правилах после официального объявления.
9. В /admin/users владелец может создать редакторов (без доступа к настройкам).

ЛОКАЛЬНЫЙ ЗАПУСК НА WINDOWS
- Установите PHP 8.1+ и добавьте путь к php.exe в PATH.
- Запустите START-WINDOWS.bat
- Откройте http://127.0.0.1:8788/install

ЛОКАЛЬНЫЙ ЗАПУСК НА LINUX / MACOS
Из корня архива выполните:
  php -S 127.0.0.1:8788 -t public public/router.php
Затем откройте http://127.0.0.1:8788/install

ЕСЛИ ХОСТИНГ НА NGINX
Установите document root на public и используйте:
  location / { try_files $uri $uri/ /index.php?$query_string; }
  location ~ \.php$ { ...ваша стандартная конфигурация PHP-FPM... }
  location ~* ^/uploads/.*\.(php|phtml|phar)$ { deny all; }
Для Apache включены rewrite-правила в public/.htaccess.

ПОСЛЕ УСТАНОВКИ
- / — главная база знаний, /admin — редактор и админ-панель.
- Для статьи: # заголовок, ## подзаголовок, **жирный**, - пункт, [название](https://адрес).
- Для изображений: /admin/media → «Копировать код» → вставить в текст статьи.
- Для резервной копии сохраните private/data.json И public/uploads.
- При переносе не заменяйте существующий private/data.json, иначе потеряются аккаунты и статьи.
- Не публикуйте файл INSTALL.txt в интернете и не храните его в доступной извне папке.
