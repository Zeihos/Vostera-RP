# Участие в разработке VOSTERA ROLEPLAY

Спасибо за желание помочь. Проект развивается открыто, но код игрового сервера и материалы третьих лиц можно добавлять только при наличии соответствующих прав.

## Как предложить изменение

1. Проверьте существующие [Issues](https://github.com/Zeihos/Vostera-RP/issues).
2. Для ошибки приложите шаги воспроизведения, ожидаемый и фактический результат, версии PHP/ОС. **Не прикладывайте пароли, ключи, данные игроков и приватные логи.**
3. Создайте ветку с понятным именем, например `fix/forum-login` или `docs/deployment`.
4. Старайтесь не смешивать рефакторинг, изменения интерфейса и исправления безопасности в одном PR.
5. Добавьте или обновите тесты. Укажите, что именно запускали локально, что проверил CI, а что не проверялось.
6. Откройте Pull Request с кратким описанием изменений и рисков развёртывания.

## Проверки

Из корня репозитория:

```bash
python3 tools/check_repository.py
python3 tools/test_install_bootstrap.py
python3 tools/test_mod_preflight.py
python3 tools/test_web_smoke.py
php Сайт/tests/test_samp_query.php
```

Для проверки синтаксиса PHP можно использовать `find Сайт Форум Вики -name '*.php' -print0 | xargs -0 -n1 php -l` в Linux. Публичные PR должны проходить GitHub Actions.

## Требования к изменениям

- Исходные тексты, комментарии и пользовательский интерфейс — преимущественно на русском языке.
- Сохраняйте совместимость с PHP 8.1+, если изменение требований заранее не согласовано.
- Не коммитьте созданные на сервере файлы `private/data.json`, `private/store.json`, `install.key`, `app.key`, `.env`, дампы баз данных, неизвестные DLL/EXE и чужие закрытые ассеты.
- Не меняйте файловую схему данных без миграции и инструкции резервного копирования.
- Для безопасности не скрывайте предупреждения, а исправляйте причину. Успешный CI не заменяет ручное тестирование в игре.

Сообщения о реальных уязвимостях отправляйте **приватно** — порядок указан в [SECURITY.md](./SECURITY.md).
