VOSTERA ROLEPLAY — УСТАНОВКА ФОРУМА

Требования: PHP 8.1 или выше с расширениями json, session, openssl.
Отдельная база данных и Composer не требуются.

1. Для хостинга: настройте корневую папку домена на /public из этого архива.
   Папка private должна остаться РЯДОМ с public и быть недоступна из веба.
   Дайте PHP право записи в private (для файла store.json).
2. Откройте https://ваш-домен/install и введите установочный ключ:
   fA0TFK-qT-UXZIMs0scV99AWn_Wa5EUg
3. Создайте первого администратора, укажите адрес сайта (если есть) и войдите.
4. При необходимости настройте ссылки VK, Telegram и сайт в private/config.php,
   а разделы, права и пользователей — через панель администратора /admin.
5. Обязательно используйте HTTPS. Сделайте резервные копии private/store.json.

Локальный запуск в Windows:
   - установите PHP 8.1+ и добавьте php.exe в PATH;
   - дважды щёлкните START-WINDOWS.bat;
   - откройте http://127.0.0.1:8787/install.
Linux/macOS: php -S 127.0.0.1:8787 -t public public/router.php

ВАЖНО: не переносите private в public. Если домен уже настроен на старый сайт,
используйте субдомен forum.ваш-домен с корневой папкой /public.
