VOSTERA ROLEPLAY — ФОРУМ

ТРЕБОВАНИЯ: PHP 8.1+, расширения json, session, openssl.

ПЕРВАЯ УСТАНОВКА
1. Разместите public/ и private/ рядом, корнем домена назначьте только public/.
2. На сервере в каталоге Форума запустите: php tools/prepare-install.php
   Если нет CLI-доступа, создайте ключ локально перед безопасной загрузкой на сервер.
3. Сохраните одноразовый ключ из терминала. Не публикуйте его в GitHub или чате.
4. Откройте https://ваш-домен/install и создайте первого администратора.
5. При успешной установке файл private/install.key автоматически удаляется.
6. Настройте ссылки в private/config.php и права групп в /admin.

Если до установки был старый ключ, замените его:
php tools/prepare-install.php --rotate
После установки НЕ запускайте команду повторно.

Храните private/store.json и копии данных за пределами public/.
Обязательно включите HTTPS и делайте резервные копии.

Локальный запуск: php -S 127.0.0.1:8787 -t public public/router.php
