# VOSTERA Starter — оригинальный игровой прототип

Это **новый самостоятельно написанный, минимальный** Pawn-режим для проверки цепочки `исходник → официальный компилятор → AMX`. Он **не заменяет** ранее подготовленный большой мод VOSTERA v0.10 Dev. Его цель — получить рабочую, воспроизводимую основу и постепенно создавать собственные механики.

## Уже заложено

- Спавн в Los Santos, демонстрационный автомобиль.
- Локальный RP-чат в пределах 30 игровых единиц, с учётом интерьера и виртуального мира.
- Команды `/help`, `/rules`, `/stats`, `/me`, `/do`.
- **Курьер:** `/job courier`, затем `/work` — появляется красный чекпоинт в Los Santos. Только достижение нужного чекпоинта приносит $125; `/cancelwork` отменяет заказ без награды.
- **Механик:** `/job mechanic`, затем `/work` — ремонт действительно повреждённой машины (прочность ниже 950) рядом с стартовой мастерской. За успешный ремонт $100.
- Общая задержка между **завершёнными** заказами — 90 секунд. В процессе заказа курьера повторный `/work` не приносит денег. Смена профессии, смерть и выход отменяют доставку.
- Обнуление временного состояния при подключении/отключении игрока.

> **Предупреждение:** здесь пока нет безопасных аккаунтов, базы данных, защиты экономики от обхода через переподключение, прав администратора, лаунчера и CEF. Не запускайте как production RP-сервер. Даже успешная компиляция не подтверждает работу на игровом сервере.

## Сборка

Для Linux доступна автоматическая сборка в [GitHub Actions](../../.github/workflows/pawn-starter.yml). Отдельный скрипт: `bash Мод/tools/build-prototype.sh` из корня репозитория. Он скачивает официальный компилятор open.mp **v3.10.11**, проверяет его SHA-256 и закрепляет исходники [omp-stdlib](https://github.com/openmultiplayer/omp-stdlib) на конкретном коммите.

Компиляция должна завершаться **без предупреждений**; предупреждения также считаются ошибкой CI. Скомпилированный `Мод/build/vostera_starter.amx` сохраняется как артефакт **только для тестирования**. В Git исходный код попадает без бинарных файлов и без данных игроков.

Для игрового теста нужен отдельный open.mp-сервер и его правильный `config.json`; при переносе замените список `pawn.main_scripts` на имя скомпилированного файла. Не подключайте этот прототип к существующей рабочей базе данных.

## Ручной игровой тест (после сборки и запуска сервера)

1. Подключиться, выполнить `/job courier`, `/work` — появится чекпоинт; до прибытия деньги не выдаются.
2. Повторить `/work` во время доставки — выплаты нет. Ввести `/cancelwork` — чекпоинт исчезает, выплаты нет.
3. Снова запустить доставку, доехать до чекпоинта — награда $125 и счётчик +1; повторный `/work` до 90 секунд блокируется.
4. Во время новой доставки сменить профессию, умереть или выйти — маршрут должен отмениться.
5. У механика проверить отказ без автомобиля, на исправной машине, вдали от мастерской; повреждённая машина у мастерской ремонтируется за $100.

Ручные проверки пока **не выполнены**. В CI проверяется компиляция исходника и структура команд, не игровой сервер.
