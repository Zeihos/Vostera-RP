# VOSTERA ROLEPLAY — игровой мод

Последняя локально подготовленная версия исходников в истории разработки — **v0.10 Dev**. В этом репозитории исходный файл `gamemodes/vostera.pwn` **пока не размещён**. Компиляция в `.amx`, запуск и игровые тесты не подтверждены.

Для следующего этапа разработки нужно загрузить исходники и ресурсы, **на публикацию которых есть права**, без логов, реальных баз игроков, паролей, закрытых CEF-ресурсов и сторонних бинарников неизвестного происхождения.

Ожидаемая структура:

```text
Мод/
  gamemodes/vostera.pwn
  pawno/include/...
  scriptfiles/serverconfig.example.ini
  tools/...
```

План технической проверки:

1. Компиляция Pawn с закреплённой версией компилятора и проверенными библиотеками.
2. Безопасная инициализация MariaDB и тест чистой схемы SQL.
3. Авторизация, миграция хешей паролей, права команд и асинхронные SQL-запросы.
4. Совместимость с клиентом SA-MP/CR:MP и CEF, игровое тестирование.
5. Только после проверки — релизная сборка и инструкция развёртывания.

**Предупреждение:** ранее найденные в интернете «сливы Rodina RP» не подтверждены как исходники, разрешённые к публичному распространению. Поэтому они не копируются автоматически в открытый репозиторий.

## Проверка локального исходника

После размещения разрешённых к публикации файлов выполните:

```bash
python3 Мод/tools/preflight.py --root Мод
```

Инструмент проверяет наличие `.pwn`, список `#include`, конфигурацию `server.cfg` и предупреждает об отсутствующем AMX. Он не выполняет компиляцию, не запускает сторонние EXE/DLL и не заявляет о готовности мода к релизу.

### Диагностика имён include

Проверка понимает Pawn-библиотеки с точкой в названии, например `Pawn.CMD` и `Pawn.RakNet`, и корректно ищет `Pawn.CMD.inc`/`Pawn.RakNet.inc`. Отсутствующие обязательные библиотеки теперь считаются ошибкой, а не просто предупреждением. `ready_for_compile: true` **не означает** успешную компиляцию или работоспособность AMX.

## Оригинальный прототип и компиляция

В папке [`prototypes/`](./prototypes/) добавлен **отдельный авторский Pawn-прототип** с начальным спавном, локальными RP-командами и временными профессиями. Его можно компилировать автоматически через [GitHub Actions](../.github/workflows/pawn-starter.yml) командой `bash Мод/tools/build-prototype.sh`.

Компилятор openmultiplayer/compiler v3.10.11 скачивается с проверкой SHA-256, официальный `omp-stdlib` закреплён на конкретном коммите. Тестовый AMX сохраняется только как артефакт сборки. **Он не является релизом VOSTERA или восстановлением старого мода v0.10**. Настоящая интеграция с MariaDB, аккаунтами, клиентом, CEF и игровым миром пока не реализована.
